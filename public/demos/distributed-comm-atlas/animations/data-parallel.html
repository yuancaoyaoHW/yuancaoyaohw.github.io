4.7 数据并行策略

DP 与 DDP 的差别不在 API，而在谁承担梯度归约与同步。DP 用一个进程里的多个线程控制多块 GPU，梯度汇聚到 GPU 0；DDP 每块 GPU 一个进程，梯度由 NCCL 在 GPU 之间就地归约。

多 GPU 训练通常应优先评估 DDP。在两块 GPU 上做原型时，DP 也可能因集成简单而适用，但要接受它的性能限制。
