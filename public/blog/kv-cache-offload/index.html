KV Cache Offload
有影响力论文调研

📅 2026-07-25 📚 OpenAlex 626 篇 + arXiv 🔬 按引用数排序

LLM 自回归解码时需为每个 token 保存 K/V 矩阵,显存占用随上下文长度线性增长。当 batch×seq_len 增大,显存装不下,必须把部分 KV cache offload 到更慢的介质(CPU 内存 / NVMe SSD),用时再换回 GPU。整个领域的技术路线围绕"何时换出、换到哪、怎么少换、换了怎么快速换回"展开。

01 必读文献（分层）

A · 经典奠基（2013–2023）

Efficient Memory Management for LLM Serving with PagedAttention vLLM
1189 cites2023 · SOSP
把 OS 分页机制引入 KV cache 管理,碎片从 60%→<4%,吞吐 2-4×。 KV cache 管理的奠基论文,定义了"显存碎片"问题与分页范式
FlexGen: High-Throughput Generative Inference of LLMs with a Single GPU
47 cites2023 · ICML
首次系统化 CPU offload:把权重+KV cache offload 到 CPU 内存/NVMe,单卡跑 175B。 offload 路线的开山之作,定义了 offload 的 trade-off 公式
LLM in a flash: Efficient LLM Inference with Limited Memory
84 cites2024 · ACL
苹果提出的 flash→DRAM 二级 offload,按需加载权重+KV 片段。 给出"受限内存下的二级存储 offload"范式

B · 方法跃迁（2024–2025）

CacheGen: KV Cache Compression and Streaming for Fast LLM Serving
78 cites2024 · SIGCOMM
把 KV cache 当"数据流"压缩+流式传输,减少 offload 带宽。 网络/存储视角的 KV offload,突破纯显存视角
PowerInfer: Fast LLM Serving with a Consumer-grade GPU
97 cites2024 · ASPLOS
异构 GPU-CPU 推理引擎,热 KV 留 GPU、冷 KV offload CPU。 消费级硬件 offload 的标杆实现
vAttention: Dynamic Memory Management for Serving LLMs without Paging
28 cites2025 · ASPLOS
用虚拟内存(非分页)做 KV 管理,避免分页开销。 挑战 PagedAttention 的范式,提出"无分页"路线
Mooncake: A KVCache-centric Disaggregated Architecture for LLM Serving
13 cites2024 · arXiv
把 KV cache 当独立资源池化,分离 prefill/decode 集群。 生产级 KV 中心架构(月之暗面),真实部署视角

层级化 KV 压缩,减少 offload 量。压缩而非换页的替代路线
TwinPilots: A New Computing Paradigm for GPU-CPU Parallel LLM Inference
17 cites2024
GPU-CPU 真并行(非 offload)。重新定义 offload 为协作
ServerlessLLM: Low-Latency Serverless Inference for LLMs

serverless 场景下 KV cache 的快速加载。云原生 offload 视角
PowerInfer-2: Fast LLM Inference on a Smartphone
