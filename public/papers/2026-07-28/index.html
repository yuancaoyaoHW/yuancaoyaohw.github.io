Compute Globally, Materialize Locally: The Memory Contract of Sparse Event-KV

⭐⭐⭐⭐☆ (4/5)
作者: Zefeng Cai, Zerui Cai  |  机构: Independent Researchers  |  分类: cs.AI  |  日期: 2026-07-28
arXiv · PDF
长周期智能体越来越多地将 KV cache 作为记忆复用:服务系统保留部分缓存条目并丢弃其余。驱逐和情景记忆方案建立在一个很少被直接验证的前提上——被保留的事件在产生它的观测消失后仍然是有信息的。本文通过从服务内容中省略一个较早的观测来测试这一前提,发现对该观测敏感的条目答案压倒性地跟随被省略的值,尽管所服务的 span 从未说明哪个值正确。作者将此称为"语义物化":下游事件的缓存行可作为计算的独立可服务视图,即使其输入已消失。该原语也可被有意编程:一段刻意设计的无答案事件可将 Qwen3-8B 上的捐赠者对齐恢复率从 6% 提升至 51%。

核心贡献

  • 揭示选择 KV 行并非仅选择其可见 token 内容:源被忽略后,Qwen3-8B 上捐赠者对答案为 99:0,证明驱逐/记忆策略选择的不只是文本
  • 该原语可编程:刻意设计的无答案"载体"事件将 Qwen3-8B 捐赠者对齐恢复率从 6% 提升至 51%,而被动收集自然提及不可靠
  • 形式化支配合约:触发器(表面形式而非语义)、落地(根承载主要信号)、访问(紧凑状态包络:二进制 .934 vs .5 随机)
  • 驱逐推论:丢弃源事件且未观察到精度下降并不能证明该源不必要——保留的行可能已携带答案

主要结论

  • 独立可服务的源被忽略事件行可携带被忽略上游计算的结论,稀疏事件 KV 服务不仅仅是行检索
  • 该原语受合约约束:触发器为表面形式,落地在根部,访问为紧凑状态包络(二进制恢复 .934 vs .5 随机)
  • 对驱逐者而言,"无精度损失"不等于"源不必要"——可重用 KV 可作为语义记忆底物

实验结果

  • §3 表1:源被忽略的捐赠者对在 Qwen3-8B 上为 99:0(p=3.2e-30),Ministral-3-8B 为 90:1,Gemma-4-12B 为 80:0;256 对重复实验中 130 个跟随/0 个反向/125 个恒定
  • §3:逐字捐赠者短语仅转移 9.7%,语义极性为 64%;显式重置覆盖携带内容(96/96 更新获胜)
  • §6 访问边界:二进制状态恢复 .934[.896,.958] vs .5 随机;四向 .223 vs .25;八向 .156 vs .125;三位数数字 0/192(从不)
  • §7:刻意无答案 NL 计算指令将捐赠者对齐恢复率从 6% 提升至 51%(Qwen3-8B);真实对话中被动收集无可检测收益
  • §7:通过附加 p-token 补丁状态更新成本为 O(pL+p²) vs O(L²) 前缀重新计算
为什么重要: 首次形式化稀疏事件 KV 服务的"记忆合约",揭示 KV 行可独立携带被丢弃源事件的计算结论,对基于精度的 KV cache 驱逐策略评估有根本性影响

Inference-Time Consensus for Mitigating Hidden Behaviors from LLM Fine-Tuning

⭐⭐⭐⭐☆ (4/5)
作者: Adhyyan Narang, Artin Tajdini, Claire Zhang, Jamie Morgenstern  |  机构: University of Washington  |  分类: cs.AI  |  日期: 2026-07-28
arXiv · PDF
微调语言模型即使在小量投毒数据上也可能植入定向不良行为,表面无害数据也可传递广泛泛化的隐藏偏好。标准防御(数据过滤、混合无害数据、正则化)可减弱但无法消除这些效果。本文转而通过冗余实现鲁棒性:从不同来源收集多个数据集,仅学习它们之间的共同行为。对每个来源数据集微调独立参考模型,在解码时聚合它们的下一个 token 分布。提出两种共识解码器:token 级最小值(将每个 token 限制为任一来源的最低概率)和基准相对最小值(在来源方向分歧时回退到基准概率)。在投毒、亚阈值学习和涌现性对齐实验中,共识解码抑制了源特定不良行为同时保留共享的有益行为。

核心贡献

  • Lemma 1:证明对多个参考模型的 KL 正则化的解为其几何/算术平均,因此它是池化(衰减)而非否决源特定提升——无单一来源可被否决
  • 两种推理时共识解码器:最小化聚合(token 级最小值)和基准相对最小值(在方向分歧时回退到基准)
  • 跨三种威胁设置(显式前缀投毒、亚阈值学习、涌现性对齐)对比联合训练、LoRA 权重合并和整体输出共识采样
  • 放宽协议:法定人数聚合(q-th 最大值替代全票通过)和语义平滑(基于嵌入的意图匹配)

主要结论

  • 当有益行为跨源重复而不需要的行为源特定时(支持-边际假设),共识解码可在解码时将益处与代价分离
  • 最小化聚合通常保留更多共享行为;基准相对最小化更强烈地抑制缺乏跨源共识的变化
  • 法定人数和语义平滑将同一思想扩展到不完整支持和不同表面形式表达;防御依赖有意义的数据来源

实验结果

  • 显式前缀投毒(Qwen3-8B, rank-8 LoRA):联合训练和 LoRA 合并同时保留共享"Joke:"益处和私有前缀;π_min 和 π_Δ 均在无弃权下抑制前缀
  • 亚阈值学习:联合/合并保留笑话但不保留隐藏动物偏好;π_Δ 在保持最多笑话的同时最接近基准动物画像
  • 涌现性对齐(5 个不良医学分片+1 良性,Qwen2.5-7B):π_min 和 π_Δ 降低广域和严格不良医学建议,而联合/合并保留更多医学失败
  • 部分支持(m=4,q=3):精确共识抑制前缀但丢失笑话;法定人数(q=3)恢复大部分益处同时仍抑制前缀
  • 表面形式分歧("Joke:" vs "Humor:"):语义平滑(BGE 编码器)恢复 109/128 最终标记,仅 1/128 私有前缀
为什么重要: 从理论(Lemma 1: KL 正则化是池化而非否决)和实验双重验证多数据源微调安全性,为 LLM 微调供应链安全提供了解码时防御新范式

Co-Evolving Graph and Text Memory for Training-Free Multi-Hop Question Answering

⭐⭐⭐⭐☆ (4/5)
作者: Hieu Man, Thien Huu Nguyen  |  机构: University of Oregon  |  分类: cs.CL  |  日期: 2026-07-28
arXiv · PDF
多跳问答需要在推理步骤间协调关系和文本证据,这是单一文本语料库或知识图谱都无法提供的。现有工作通常只强调这一循环的一部分:图增强 RAG 从预构建或查询更新的图中检索,KGQA 系统在主题中心子图内搜索,记忆增强智能体维护演化记忆但不持续协调图记忆与文本上下文。本文提出 Co-E,一个围绕双向同步图-文工作记忆构建的免训练系统。同步周期整合文本记忆、抽取关系三元组到图记忆、并将图事实回写到生成上下文中。因为两种记忆都持续维护,它们共同塑造后续检索和生成。在六个多跳问答基准上,Co-E 优于可比的免训练开放主干基线,并与更大或经过训练的系统竞争。

核心贡献

  • 提出 Co-E,一个无需训练的多跳问答系统,核心是双向同步的图-文工作记忆机制
  • 设计四操作同步周期:文本整合→文本到图传播(抽取三元组并合并)→图到文本传播(回写自然语言)→二次整合
  • 双流检索:记忆条件的语料检索(web/稠密)+记忆条件的图检索(实体链接+k-hop SPARQL,重排序剪枝)
  • 支持 MCTS 与 CoT 两种推理模式,搜索统计与共享工作记忆分离

主要结论

  • 多跳问答应将推理视为迭代记忆维护问题:文本证据扩展图前沿,图事实回写约束后续检索与生成
  • 跨六个基准 Co-E 持续优于可比无训练基线(2Wiki 72.6 EM、Bamboogle 70.0 EM、MuSiQue 52.5 EM、CWQ 74.9 Hits@1)
  • 消融表明双向传播与主动维护均必要:去除双向同步 Bamboogle MCTS 从 70.0 降至 61.1,去除主动维护降至 49.5
  • Full-Wikidata 压力测试下仍保持较强组合式 KGQA 能力(CWQ 73.4),证明图-文共演化是实用机制

实验结果

  • KGQA:Co-E(MCTS) WebQSP 85.5 Hits@1、CWQ 74.9 Hits@1,优于 PoG(74.7)、iQUEST(73.9)
  • 多跳文本问答:2Wiki 72.6 EM、Bamboogle 70.0 EM、MuSiQue 52.5 EM、HotpotQA 61.8 EM,为开放≤8B 系统中最强
  • 消融(Bamboogle):去双向同步 MCTS 70.0→61.1、CoT 66.4→52.5;去主动维护 MCTS 降至 49.5
  • Full-Wikidata 压力测试:CWQ 74.9→73.4(小幅),WebQSP 85.5→78.6(短问题受检索噪声影响更大)
  • 失败分析(Bamboogle):检索缺口 45%、推理链不完整 21%、实体链接错 14%、综合错 14%
为什么重要: 首个将图-文工作记忆双向同步用于免训练多跳问答的系统,消融充分证明双向传播与主动维护的必要性,为多跳推理提供了无需训练的新范式

ConsistencyGate: Preventing Memory Contamination in LLM Agents via Self-Consistency Admission Control

⭐⭐⭐⭐☆ (4/5)
作者: Yan Zhang, Shibo Li  |  机构: Florida State University  |  分类: cs.CL  |  日期: 2026-07-28
arXiv · PDF
跨多轮运行的 LLM 智能体在外部记忆中积累事实并复用为下游推理前提。某步写入的幻觉事实因此作为错误前提持续存在,作者称之为"记忆污染"。现有记忆管理处理检索和容量但不处理写入正确性;该准入问题无法由基于效用或时效性的标准解决,且未受控污染在长轨迹上复合累积。本文提出 ConsistencyGate,一个写入时准入门:在提交候选事实前,查询 LLM K 次获取软支持分数,仅当均值超过阈值时才准入。该机制模型无关、免微调,并提供单次前向传播的 log-probability 变体用于延迟敏感场景。在四个 LLM 骨干上,ConsistencyGate 在每个基准上都降低了污染。

核心贡献

  • 首次将 LLM 智能体记忆污染形式化为写入时准入问题,证明其随轨迹长度复合累积
  • 提出 ConsistencyGate——模型无关、免微调的写入准入门,通过 K 次自一致性软打分取均值与阈值比较;提供单次前向 LogProb 变体和无调参自适应阈值回退
  • 构建并开源三个基准:合成 MemContam(隔离近 oracle 上界)+ 首个带可控植入污染的真实对话基准 LoCoMo-Contam 与 MSC-Contam
  • 在 4 个 LLM 骨干上系统验证一致性与跨模型泛化

主要结论

  • 记忆污染的写入时准入是已有记忆管理的必要补充:早期准入决策决定后期记忆质量
  • 基于自一致性的正确性准入无需微调即可在真实对话与合成语料上持续降低污染(真实数据降幅 20%-62%)
  • 一致性仅为正确性代理,不能替代权威事实核查;在隐式陈述事实上存在召回率代价(LoCoMo-Contam Recall=0.58)

实验结果

  • MemContam 合成基准:污染从 50.0% 降至 1.2%(相对降 97.6%),QA F1 由 0.474 升至 0.840(近 oracle 上界)
  • 真实对话基准:LoCoMo-Contam 污染降至 34.1%(精度 0.500→0.659)、MSC-Contam 降至 36.7%(精度 0.633)
  • 跨模型泛化(4 骨干):真实对话污染降幅跨度 20%(Scout/MSC)到 62%(Gemma 与 Llama-3.3-70B/LoCoMo-Contam)
  • 污染级联效应:随交互轮次增大 WriteAll 污染恒为 50%、QA F1 饱和 0.45,ConsistencyGate 第 90 轮降至 <3%、QA F1 升至 0.88
  • 消融:K 从 1 增到 10 仅 1-2 点边际增益(推荐 K=5);LogProb 变体在 MemContam 近完美精度 1.000,延迟 23-28ms,加速 12-14×
为什么重要: 首次将 LLM agent 记忆污染形式化为写入时准入问题并提出免微调解法,对长周期 agent 系统的可靠性有直接工程价值

Not All LLM Reasoning is Visible in the Chain-of-Thought

⭐⭐⭐⭐☆ (4/5)
作者: Vatsal Baherwani, Tom Goldstein, Ashwinee Panda  |  机构: New York University; University of Maryland; TogetherAI  |  分类: cs.CL  |  日期: 2026-07-28
arXiv · PDF
AI 安全的一个关键问题是语言模型是否在输出 token 中表达了全部推理。本文展示了一个具体的失败模式:前沿模型利用语义无关的填充 token——对所有问题都相同的固定无语义 token 序列——来提升合成推理任务性能,且提升最高达 13 个百分点。这种收益取决于使用哪些 token 并因模型而异。进一步显示,填充 token 使 Claude Opus 4.5 能在不牺牲主任务准确率的情况下满足隐藏的模运算约束,证明不可见推理可以服务于对 CoT 监控完全不可见的目标。RL 赋予 Qwen3-235B 对填充 token 内容的强偏好,但 RL 和 SFT 均未产生测试时持久的填充 token 收益。

核心贡献

  • 系统性形式化"不可见推理"概念:模型前向计算中发生在潜空间、且在输出 token 中无任何可解释痕迹的因果性计算;基于填充 token 设计三条诊断准则
  • 在 13 个前沿模型(含 GPT-5.2/5.5、Claude Opus 4.5/4.6、Gemini 3、Qwen3-235B 等)上证明:无需额外训练即可利用填充 token 提升性能,最高达约 13 个百分点
  • 揭示"type inversion"与任务/少样本依赖:同一 token 类型在 zero-shot 中有害、在 10-shot 中却最有益
  • 设计隐藏约束实验:填充 token 使 Claude Opus 4.5 在不牺牲主任务准确率的情况下满足隐藏模运算约束

主要结论

  • 前沿模型已在无任何显式优化条件下,于无语义 token 中执行产生后果的计算,证明 CoT 监控假设在根本上不成立
  • 不可见推理的提升取决于填充 token 类型、少样本设置与任务三者交互,信号分布在整段填充序列、由早期层驱动
  • RL 能赋予 Qwen3-235B 对填充 token 内容的强偏好,但既不能产生测试时持久的填充 token 收益,也未通过 SFT 迁移

实验结果

  • 17 种填充 token × 3 任务(4 位乘法/多步算术/代码变量计数)× zero/5/10-shot 的 Qwen3-235B 扫描:出现"type inversion"现象
  • 跨 13 个前沿模型对比:Opus 4.6 算术提升 +30.0、Opus 4.5 算术 +11.2/乘法 +10.0、Gemini 3 算术 +10.7;GPT-5.5 乘法从 98.5%→100%
  • 隐藏约束实验:对"x mod 2=1",Opus 4.5 从 33.5%→44.5% 且主任务准确率不降;Qwen3-235B 达 98.8% 但伴随主任务下降
  • 机制分析:animals→Fibonacci 顺序恢复大部分提升而反向更差;0-30 层激活 patching 恢复 >90% 性能差距;attention masking 后 zero-shot 乘法提升仍存
  • RL 训练 Qwen3-235B 114 步:基线 zero-shot 乘法从 42.0% 升至 66.5%,但 pass@1 几乎无增益、pass@8 仅 +1.07%,SFT 完全无法迁移
为什么重要: 证明前沿模型在输出 token 中存在 CoT 监控完全不可见的"不可见推理",对 AI 安全中的 CoT 监控假设提出根本性挑战

Two Regimes of Chain-of-Thought Unfaithfulness: Behavioral Detection Fails Where Models Are Wrong

⭐⭐⭐⭐☆ (4/5)
作者: Suramya R. Angdembay, Dikshant Aryal, Nick Rahimi  |  机构: The University of Southern Mississippi  |  分类: cs.CL  |  日期: 2026-07-28
arXiv · PDF
CoT 解释只有在忠实(即所述推理实际产生了答案)时才能支持监督。本文对 FaithCoT-Bench 的人类标注进行行为审计,发现答案正确性在每一层结构化该问题。仅答案错误性(一个不可部署的 oracle 诊断,AUROC 0.696)就优于每个专门构建的信号,因为 69% 的标注不忠发生在错误答案上。按正确性分层将检测分为两个 regime:正确答案上行为信号中等分离忠实与事后推理(0.63-0.67);错误答案上(大多数不忠所在处)没有测试信号可检测地高于随机。标准 step-removal 指标与人类标签反相关;该反转在基准发布的分数和提示依赖的反事实标注轨迹上均重现。线性探针在 Llama-3.1-8B 中解码行为盲区,在 Qwen-2.5-7B 中解码正确答案 regime,无共享方向。

核心贡献

  • 按答案正确性分层人类标注的 CoT 忠实性检测,揭示两个对立的"regime"(正确 vs 错误答案),先前工作将两者混淆
  • 对 FaithCoT-Bench 的黑盒审计(4 信号族)显示答案错误性(AUROC 0.696)优于所有专门构建的检测器,标准 step-removal 指标与人类标签反相关
  • 线性探针在不同模型中分别解码两个 regime(Llama 盲区/错误 regime;Qwen 正确 regime),无共享跨 regime 方向——白盒补充行为但无单一探针捷径
  • 迁移验证两个构造测试床(7 模型指令构造 + 提示诱导反事实),并独立验证和解决基准标签语义文档-数据不匹配

主要结论

当大语言模型从孤立任务求解转向长期服务人类环境时,它们需要社交智能:推断心理状态、追踪社会关系、推理规范并在上下文中适应行为。本报告提出 Zhijing,一个集成评估、内化和基础化社交智能的框架。评估方面引入 SoMBench(基于心理学,3 个一级维度、17 个二级维度、71 种任务范式、3481 个专家验证实例),20 个代表性 LLM 中最佳仅达 72.08%。内化方面开发 Zing(诊断驱动训练:SFT + 在策略蒸馏 + 基于评分准则的 RL)。基础化方面构建 Actio(测试框架推理架构,路由四种类型化支持:PRISM 程序性指导、Starling 运行时心理状态表征、SAGE 可重用经验、门控 RAG 外部社交/规范知识)。在五个社交认知基准上 Zing 持续优于基础模型,Actio 在 15 对模型-基准中提升 14 对。

核心贡献

  • SoMBench:基于心理学的社交智能基准,跨越 3 个一级维度、17 个二级维度、71 种任务范式,3481 个专家验证实例,控制问题格式/叙事视角/上下文长度
  • Zing:诊断驱动的分阶段训练方案(SFT + 在策略蒸馏 + 基于评分准则的 RL),将社交推理内化为稳定的基础模型能力
  • Actio:基于测试框架的推理架构,将四种类型化支持(PRISM/Starling/SAGE/门控 RAG)选择性路由到推理中
  • 将评估、参数化内化和部署时基础化连接成统一技术路线

主要结论

  • 当前大模型社交智能仍有很大提升空间——SoMBench 上最佳模型仅达 72.08%,17 个二级维度中无一达到 90% 近天花板区间
  • 社交推理可通过诊断驱动监督和分阶段训练内化为稳定能力,在所有模型规模上均优于基础模型
  • 部署时基础化受益于跨类型化支持(而非统一上下文扩展)的选择性路由
