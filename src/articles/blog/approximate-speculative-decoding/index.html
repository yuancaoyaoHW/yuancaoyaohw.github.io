Approximate Speculative Decoding：复用贪心后缀的近似投机解码

arXiv:2608.03447 · 北京大学 · 2026-08-04

论文: Approximate Speculative Decoding

作者: Yuannuo Feng 等

机构: 北京大学

链接: arXiv:2608.03447

一句话总结：标准投机解码在首个与目标 argmax 不一致的 draft token 处就截断，丢弃该 token 之后已被目标模型评分的整个后缀。ASD 用预算化的最长前缀选择替代二元截断——接受受限的不匹配，复用后续连续的目标贪心后缀，无需额外近似决策或目标模型前向传播，零预算时精确退化为标准贪心验证。

1. 问题：首次不匹配即截断

投机解码（Speculative Decoding）用一个小而快的 draft 模型并行猜测一个 token 块，再由大而准的目标模型一次性并行验证整个块。贪心验证下，解码在第一个与目标 argmax 不同的 draft token 处停止，丢弃该位置之后的所有 token——尽管它们已经被目标模型评过分了。

这造成明显的浪费：

  • 目标模型已经为 draft 块中每个位置产出了完整的 logit 分布
  • 第一次不匹配之后的 token，目标模型其实已经算好了 argmax
  • 但标准协议直接丢弃这些已评分后缀，下一轮重新起草

关键观察：接受一个不匹配虽然改变了解码轨迹，但如果后续 token 在实现前缀下仍是目标贪心选择，那么连续后缀可以被复用——不需要再做任何近似决策或目标模型前向传播。

2. ASD 核心思路：复用贪心后缀

ASD（Approximate Speculative Decoding）用一个预算化的最长前缀选择替代二元首次不匹配截断：

  1. 接受选定不匹配：不再在首次不一致处停下，而是在三级预算约束允许的范围内，接受最长的可接受前缀
  2. 复用连续目标贪心后缀：被接受的不匹配之后，如果后续 token 恰好是目标模型在该前缀下的 argmax，则连续后缀直接复用
  3. 无训练无微调：不改动任何模型权重，只改变验证协议

为什么有效：目标模型已经在 draft 块的每个位置算出了完整分布。标准协议丢掉的是"已经算好但没用"的信息。ASD 把这部分免费信息捡回来——只要不匹配的"代价"（logit 遗憾）在预算内，复用就比重新起草更划算。

零预算退化：当总预算 $B = 0$ 时，ASD 拒绝一切不匹配，精确退化为标准贪心验证。这意味着 ASD 是标准协议的严格推广——预算越大，复用越多，加速越明显。

3. 三级预算约束

ASD 不是无脑接受所有不匹配——那样会严重偏离目标模型的贪心轨迹。它通过三级预算约束控制近似误差，每一级过滤掉一部分不匹配：

第一级：局部目标 logit 遗憾门 $g$

对每个 token 位置 $i$，计算logit 遗憾：

$$z_i(y_i^*) - z_i(x_i)$$

其中 $y_i^*$ 是目标模型在该位置的 argmax，$x_i$ 是 draft 选的 token。遗憾为 0 表示 draft 选对了；遗憾越大表示 draft 偏离越严重。门控要求每个被接受的不匹配 token 的遗憾不超过阈值 $g$。

第二级：每块异常上限 $M$

每个 draft 块中接受的不匹配 token 数量不超过 $M$。防止整块全部不匹配被接受的极端情况。

第三级：持久请求级遗憾预算 $(B, s)$

跨块累积的总遗憾不超过总预算 $B$，$s$ 是当前已用预算。这是一个持久的、跨解码块的预算池——早期省下的遗憾可以留给后期使用，整体误差可控。

DeepSeek-V4-Flash (284B)：验证器接受率

在更大的 DeepSeek-V4-Flash（284B 参数）上，ASD 使 GSM8K 和 MATH-500 的验证器接受率提升 10%–16%。接受率越高意味着每轮复用的 token 越多，目标模型前向传播次数越少，端到端吞吐越高。

为什么大模型受益更大：模型越大，每次目标模型前向传播越昂贵。ASD 复用后缀省下的正是目标模型前向次数——所以模型越大，省下的绝对延迟越多，吞吐提升的相对比例也越显著。

5. 总结

核心贡献：

  • 用预算化最长前缀选择替代二元首次不匹配截断
  • 接受受限不匹配，复用后续连续目标贪心后缀，无需额外近似决策或目标前向
  • 三级预算（局部门 $g$ + 块上限 $M$ + 请求预算 $B$）控制近似误差
  • 无训练无微调，零预算时精确退化为标准贪心验证
  • Qwen3-14B 七任务平均 +7.78%，DeepSeek-V4-Flash 接受率 +10–16%

与标准投机解码对比：

维度标准投机解码ASD
不匹配处理首次不匹配即截断接受受限不匹配
已评分后缀丢弃（浪费）复用连续贪心后缀
误差控制无近似（精确）三级预算约束
额外前向每轮重新起草复用省去额外前向
退化行为—$B=0$ 退化为标准

意义：ASD 揭示了投机解码中一个被忽视的浪费源——目标模型已经算好但被丢弃的后缀。通过受控地接受这种"免费信息"，ASD 在不牺牲质量可控性的前提下获得了稳定的吞吐提升。这是一个协议级的改进，可以叠加在任何现有的投机解码系统之上。
