跨模型 KV 缓存迁移：同家族模型间的线性映射

arXiv:2608.03893 · NVIDIA · 2026-08-04

论文: Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse

作者: Taekyung Heo, Rasoul Shafipour, Ritchie Zhao, Maximilian Golub, Mohammad Mahdi Kamani, Ritika Borkar, Makesh Tarun Chandran, Pantea Zardoshti, Bita Darvish Rouhani

机构: NVIDIA

链接: arXiv:2608.03893

一句话总结：同家族不同大小的模型（如 Qwen3 14B→32B）之间，KV cache 存在显著的线性结构——一个闭式岭回归就能把源模型的 KV 映射到目标模型的 KV 空间，跳过 prefill，2.7–25× 更快且保持 73–98% 精度。

1. 问题：模型切换的 prefill 代价

生产部署中频繁在同家族不同大小模型间切换：

  • 成本-质量级联：简单 query 用小模型，复杂 query 升级到大模型
  • 对话中途切换：前几轮用小模型省成本，上下文积累后升级
  • 路由：按 query 类型分发到不同大小模型

每次切换，接收方必须从头重算 prefill——把已积累的长上下文重新跑一遍前向传播生成 KV cache。prefill 成本随模型大小和 prompt 长度增长，长 agentic 会话 + 频繁模型切换 = prefill 成本爆炸。

核心洞察：prefill 的产出就是 KV cache，所以跨模型复用 KV cache 本质上是一个表征空间映射问题——把模型 A 的 KV 转成模型 B 期望的格式。

2. 核心发现：KV 的线性结构

作者在 Qwen3 14B→32B 上做了一组关键实验：对每个（源层 $l'$，目标层 $l$，头 $h$），拟合单源层线性回归，测量 $R^2$（方差解释率）。

四大发现：

  1. 单层线性拟合已很强：Qwen3 14B→32B，单源层解释目标 key 56% 方差、value 32% 方差
  2. 多层组合更强：用 top-k 源层组合后，key $R^2$ 升到 0.79，value 升到 0.65
  3. 剥离 RoPE 提升拟合：去掉 RoPE 旋转后对角线更锐利——位置信息和语义内容解耦
  4. Key 比 Value 更可预测：K 的 $R^2$ 通常比 V 高约 0.2

为什么线性结构存在？ 同家族模型共享 tokenizer、核心架构选择（KV 头数和每头维度相同——称为 "matched KV"）、大量预训练数据。差异仅在层数、隐藏维度、训练配方。因此表征空间是同一组通用特征的不同线性投影，存在近似仿射映射。

3. 三步闭式映射器

基于线性结构发现，作者设计了闭式岭映射器（ridge mapper），三个组件：

动画 2：三步映射器流水线

流水线 · 5 步
速度 0 / 5

Step 1：跨层源选择

源模型和目标模型层数不同。对每个目标层，贪心选择 top-k 个最预测性的源层（按 $R^2$ 排序），拼接它们的 KV 作为输入。

k=1 只捕获 k=all 时 66% 的 K $R^2$ 和 42% 的 V $R^2$。到 k=6 时 $R^2$ 接近饱和。跨层源选择是消融实验中最大贡献者。

Step 2：内容空间映射（RoPE 解耦）

RoPE 对 key 施加位置相关旋转。直接在 RoPE key 上拟合会把权重绑死在 1024 token 的位置分布。解法是三步解耦：

源 key → 剥 RoPE (R_Θ⁻¹) → 线性映射 W_K → 加目标 RoPE (R_Θ) → 目标 key

映射权重变成位置无关的，可在任意上下文长度复用。

Step 3：逐头岭回归

对每个目标（层 $l$，头 $h$），独立拟合闭式解：

$$\mathbf{W}^* = (\mathbf{X}^\top \mathbf{X} + \lambda \mathbf{I})^{-1} \mathbf{X}^\top \mathbf{Y}$$

其中 $\lambda = 0.01$ 岭正则化保数值稳定。校准数据仅需 500 条 FineWeb-Edu 序列（1024 token，下采样到 ~128K token）。无梯度训练，纯闭式求解，单 8×H100 节点 ~47-87 分钟。

5. 失败分析：错误落在哪里比错误多大更重要

这是论文最深刻的分析。$R^2$ 不是好指标：同样的校准 $R^2 = 0.84$，Llama 8B→70B 只保留 37%（大→小），Ministral 3B→8B 保留 93%。

动画 3：错误落点分析

K-concentration · 4 步
速度 0 / 4

注意力输出余弦相似度才是预测跨对保留率的正确指标（Pearson $r = +0.57$），远优于 $R^2$（$r = -0.20$）。

注意力并不平等地读所有维度。作者定义了 K-concentration：把映射误差投影到目标 query 矩阵的右奇异向量上，按对应奇异值加权。

  • concentration > 1：误差集中在注意力读的地方 → 灾难
  • concentration < 1：误差落在注意力忽略的地方 → 无害

对 Ridge 失败的 Ministral 对，换成两层 1024-unit ReLU MLP：

模型对RidgeMLP提升
Qwen3 14B→32B97.6%97.3%-0.3pp
Ministral 3B→8B93.3%91.8%-1.5pp
Ministral 3B→14B68.0%92.3%+24.3pp
Ministral 8B→14B58.7%95.5%+36.8pp

MLP 救场的原因不是"更准"，而是把误差重新分配到了注意力不敏感的子空间（K-concentration 降低 ~2.5，余弦提升 ~0.45）。

序列越长，加速越显著——映射器只是逐层矩阵乘，而 prefill 是完整 Transformer 前向。多轮切换（CoQA 100 段 ×15 轮）中漂移也很小：小→大 10 轮仅扩大 1.7pp，大→小每轮线性漂移 0.33pp。

7. 总结

核心贡献：

  • 发现同家族跨模型 KV 的线性结构，闭式解即可映射
  • 三步设计（跨层源选择 + RoPE 解耦 + 逐头岭回归），500 条校准样本足够
  • 4/6 对保留 73–98% 精度，2.7–25× 加速
  • 失败分析揭示：错误落点比错误大小更重要，注意力输出余弦相似度预测跨对质量
  • MLP 通过重分配误差救场失败对

局限：仅 matched-KV 对、仅同家族、仅密集全注意力、单域校准。跨家族和混合架构留待未来工作。
