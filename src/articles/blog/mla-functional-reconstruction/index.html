超越 KV 重建：MLA 草稿模型的功能重建

将 MHA/GQA 转换为 MLA 可以压缩 KV cache、降低推理内存带宽，但转换引入的秩瓶颈和 RoPE 误差会改变注意力输出——这在独立生成中几乎无害，却在投机解码中导致草稿接受率骤降。本文提出端到端功能重建，在训练阶段让转换后的 MLA 注意力模块复现原始 MHA/GQA 块的 post-WO 响应，不改推理图、不需验证器监督。

背景：MLA 与投机解码的两条加速路线

大模型推理越来越受限于内存带宽而非算力。自回归解码时，每个 token 都要读取不断增长的 KV cache，服务延迟和吞吐高度依赖 cache 的表示效率。

GQA：减少 KV 头数

分组查询注意力（GQA）通过共享 KV 头来减少 cache 大小——多个查询头共用一组 K/V。但 GQA 仍然存储显式的 key 和 value 张量，cache 体积仍与序列长度线性增长。

MLA：用 latent cache 替代显式 KV

多头潜在注意力（MLA，DeepSeek-V2/V3 采用）更进一步：不再缓存完整的 K/V 矩阵，而是缓存一个低维 latent 向量 $c_j = W^{DKV} h_j \in \mathbb{R}^r$ 加一个小型位置分量 $k^{PE}_j$。非位置 K/V 从 latent 通过 absorbed projections 恢复：

$$[K_{nope}; V] = W^{UKV} \cdot c_j$$

这意味着 cache 中只存 $r$ 维 latent 而非完整的 $m = G(d_k^{nope} + d_v)$ 维 K/V，在 $r \ll m$ 时大幅压缩。问题在于：大多数能力强的开源模型（Llama、Qwen）使用 MHA/GQA，不是 MLA——需要转换。

投机解码：用草稿换吞吐

投机解码用一个小的草稿模型并行提议多个 token，目标模型一次性验证。当草稿提议与目标一致时，多个 token 被接受、目标模型前进多步。接受率直接决定加速比。

关键张力：MLA 优化的是 cache 效率（降低内存带宽），投机解码优化的是吞吐（并行验证）。两者本可叠加——MLA 草稿模型既省 cache 又加速推理。但论文发现：转换后的 MLA 模型可能是高效生成器，却是糟糕的草稿模型。

问题：转换成功 ≠ 草稿可用

现有转换方法（TransMLA、MHA2MLA）能将 MHA/GQA 检查点映射为可执行的 MLA 参数化——cache 拓扑正确、模型能生成连贯文本。但论文指出一个容易被忽略的失败模式：

核心发现：一个转换后的 MLA 模型可能是高效的生成器，却是糟糕的草稿模型。转换改变了注意力输出的概率分布，导致草稿提议与目标验证不一致，接受率骤降。

三种嵌套的成功标准

论文将"成功"拆解为三个层级，暴露了转换与草稿之间的根本矛盾：

层级问题转换方法是否满足

关键洞察是：因子级别的误差（$Q$、$K$、$V$ 的重建误差）只是间接代理——注意力组合了低秩投影、RoPE、softmax、value 聚合和 $W_O$ 才影响残差流。小误差可以相互抵消，而一个局部 logit 扰动可能跨越 token 排名边界、急剧降低接受率。因此评估不应止步于 cache 有效性或独立生成质量，还应包括接口级功能指标和匹配草稿接受率。

误差源一：秩瓶颈

MLA 将所有 KV 组的非位置 key 和 value 堆叠后从 latent 恢复：

$$[K_{nope}; V] = W^{UKV} \cdot W^{DKV} \cdot h_j$$

其中 $W^{DKV} \in \mathbb{R}^{r \times D}$，$W^{UKV} \in \mathbb{R}^{m \times r}$，$m = G(d_k^{nope} + d_v)$。要精确复现这个堆叠线性映射，需要：

$$\text{rank}(W^K W^V) \leq r$$

右端秩至多为 $r$。当原始映射的秩超过 $r$ 时，选定的压缩因子化无法精确复现 K/V 投影，必然留下残差。

为什么这很重要：这个秩条件是一个直接映射重建的判定——它既不排除所有功能等价的注意力参数化，也不否定足够大 rank 下的精确 MLA 重写。它说明的是：激进压缩、cache 有效的转换通常是原始 K/V 投影的近似。

误差源二：RoPE 处理

秩瓶颈不是唯一的失配。转换流水线还必须选择如何处理旋转位置编码（RoPE）。为使误差显式化，将原始 key 拆分为 $k_j = k_j^{keep} + k_j^{drop}$，其中 $k_j^{keep}$ 保留在旋转路径上，$k_j^{drop}$ 移至非位置路径。转换后的 query 为 $\hat{q}_t = q_t + \delta q_t$，重建的保留 key 为 $\hat{k}_j^{keep} = k_j^{keep} + \delta k_j$。

原始 logit 为 $\frac{q_t^\top R_{tj}(k_j^{keep} + k_j^{drop})}{\sqrt{d_k}}$，转换后 logit 为 $\frac{(q_t + \delta q_t)^\top [R_{tj}(k_j^{keep} + \delta k_j) + k_j^{drop}]}{\sqrt{d_k}}$。精确差为：

$$\hat{s}_{tj} - s_{tj} = \frac{1}{\sqrt{d_k}} \Big[ q_t^\top R_{tj} \delta k_j + q_t^\top (I - R_{tj}) k_j^{drop} + \delta q_t^\top R_{tj}(k_j^{keep} + \delta k_j) + \delta q_t^\top k_j^{drop} \Big]$$

四项误差分解：
  • 第一项 $q_t^\top R_{tj} \delta k_j$：保留 key 重建误差
  • 第二项 $q_t^\top (I - R_{tj}) k_j^{drop}$：位置路径误差（RoPE 路由偏差）
  • 第三项 $\delta q_t^\top R_{tj}(k_j^{keep} + \delta k_j)$：query 扰动及其与 key 重建的交互
  • 第四项 $\delta q_t^\top k_j^{drop}$：query 扰动与非位置路径的交互

这个分解揭示了：转换引入的注意力 logit 误差来自多个来源——低秩 KV 压缩的残差、RoPE 拆分路由的偏差、query 重建的扰动，以及它们之间的交互项。Softmax 将 logit 残差映射为注意力权重误差，输出残差还额外继承 value 重建误差。

为什么影响接受率

注意力 logit 的微小残差在独立生成中可能无害——softmax 是平滑的、后续层可以部分修正。但投机解码对 token 级别的排名一致性极其敏感。

贪心解码的接受条件

论文使用贪心解码验证。在固定上下文 $x$ 下，单 token 接受事件为：

$$\alpha_{\text{greedy}}(x) = \mathbf{1}\!\left[\arg\max_y p_D^x(y) = \arg\max_y p_T^x(y)\right]$$

即草稿模型和目标模型的 top-1 token 相同时才接受。这是一个离散事件——即使 logit 残差很小，只要它翻转了 top-ranked token，接受就从 1 变 0。

随机采样的接受上界

对于随机拒绝采样验证，单 token 期望接受率为：

$$\alpha_{\text{sample}}(x) = \sum_y \min\!\left(p_D^x(y), p_T^x(y)\right) = 1 - \text{TV}\!\left(p_D^x, p_T^x\right)$$

其中 TV 是总变差距离。MLA 转换增大了 $p_D$ 和 $p_T$ 之间的分布距离，直接压低接受上界。

核心矛盾：局部注意力残差与最终接受率之间没有单调关系保证。后续层可能衰减残差、放大残差，或将其投影到与决策无关的方向。功能重建是一个训练时代理——意在保持原始草稿的条件行为，其接受率效果是经验测量的而非理论保证的。

功能重建方法

论文提出端到端（E2E）功能重建——一个转换器无关、纯训练时、后转换阶段的精修步骤。

核心思路

对于每一层 $\ell$ 和校准 minibatch $b$，用缓存的层输入 $H_b^\ell$ 同时送入冻结的原始 GQA 注意力块和可训练的转换后 MLA 注意力块。两者的 post-$W_O$ 输出定义一个 masked MSE 功能误差。梯度只通过原始路径的 stop-gradient，仅更新转换器引入的 query 和 KV 投影；$W_O$ 保持冻结。

方法特点：
  • 转换器无关：从 TransMLA 或 MHA2MLA 转换后的检查点出发，不使用转换器的局部转换目标
  • 纯训练时：不引入额外推理操作、参数分支或 cache 状态
  • 无验证器监督：不需要验证器 logits、激活值、基准标签或生成目标
  • 保持 cache 拓扑：latent rank、retained-RoPE 宽度、cache 预算全部不变

为什么是 post-WO 而非因子级

转换器局部的投影重建目标是因子级别的——试图逐个复现 $W^K$、$W^V$ 等。但论文的关键洞察是：注意力在影响残差流之前组合了低秩投影、RoPE、softmax、value 聚合和 $W_O$。因子级误差只是间接代理——小误差可相互抵消，而局部 logit 扰动可跨越排名边界。

Post-$W_O$ 匹配训练的是完整注意力变换的可观测输出，而非某个转换器特定的因子化。这使得同一个目标可以精修 TransMLA 和 MHA2MLA 检查点——因为它在共享的功能接口上操作，而非假设每个转换器留下相同的误差。

E2E 损失函数

对于层 $\ell$ 和校准 minibatch $b$，令 $H_b^\ell \in \mathbb{R}^{T_b \times D}$ 包含缓存的层输入，$M_b \in \{0,1\}^{T_b}$ 标记有效 token（在隐藏维度上广播）。每层独立优化：

$$\mathcal{L}_{\text{E2E}}^{(\ell)} = \mathbb{E}_b \left[ \frac{\left\| M_b \odot \left( A_{\text{MLA}}^\ell(H_b^\ell) - \operatorname{sg}\!\left[A_{\text{orig}}^\ell(H_b^\ell)\right] \right) \right\|_F^2}{D \sum_t M_{b,t}} \right]$$

公式分解

符号含义
$A_{\text{MLA}}^\ell(H_b^\ell)$转换后 MLA 注意力块（含 $W_O$）的输出
$A_{\text{orig}}^\ell(H_b^\ell)$原始 GQA 注意力块（含 $W_O$）的输出
$\operatorname{sg}[\cdot]$stop-gradient：原始路径不接收梯度
$M_b \odot$有效 token 掩码：只计算有效位置的误差
$\|\cdot\|_F^2$Frobenius 范数平方：所有隐藏通道的平方误差之和
$D \sum_t M_{b,t}$归一化因子：每个有效 token 的每个隐藏通道取平均
"E2E"的含义：指从层输入到 post-$W_O$ 输出的完整注意力功能。因此该目标联合覆盖了 RoPE 处理误差和低秩 KV 转换误差——不像转换器局部目标只优化其中一个。损失不要求 Eq.(7) 的秩条件精确成立；它在固定压缩 MLA 函数族中搜索更近的功能匹配。

初始化策略

令 $\mathcal{C}$ 为基础 MHA/GQA → MLA 转换器。E2E 取 $\mathcal{C}(\theta_{\text{orig}})$ 作为初始化，但不复用 $\mathcal{C}$ 的局部转换目标。它只需要原始注意力块、初始化后的 MLA 块和校准隐状态。因此同一个 E2E 目标可以精修 TransMLA 和 MHA2MLA 检查点，同时保持所选转换器产生的 cache 拓扑。

恢复率分析

功能重建能校正可由有效转换块表示的近似误差，但不能创造缺失的 latent rank 或修复不兼容的张量并行/核实现。例如：

  • Qwen-3B + MHA2MLA + HF, CNN/DM：Original 58.82% → Partial 54.00% → Ours 56.29%（部分恢复）
  • Llama-1B + TransMLA + HF, HumanEval：Original 77.75% → Partial 67.61% → Ours 71.53%
  • Qwen-3B + TransMLA + vLLM, NQ：Original 71.03% → Partial 10.95% → Ours 12.73%（转换损失过大，恢复有限）

吞吐影响

功能重建是纯训练时方法，不引入额外推理操作。12 个单元显著更快，50 个不变，2 个略慢。37 个接受率改善的单元中，12 个同时显著提速。但论文坦诚：这并未建立相对于未转换草稿的端到端加速——绝对 GQA→MLA 吞吐差异混合了模型保真度和 kernel 成熟度。

总结与三级工作流

论文的核心论点是：MLA 转换和草稿效用是不同的目标。一个转换后的 MLA 检查点可能是有效的生成器，却是糟糕的投机草稿——因为 latent cache 施加秩约束、RoPE 处理扰动注意力 logit。

三级工作流

层级任务验证方法
1. 转换建立 cache 高效的参数化验证 RoPE、张量并行、kernel 正确性
2. 功能重建在固定部署预算下优化转换后注意力映射E2E MSE 损失 + 校准隐状态
3. 部署验证测量匹配接受率和后端吞吐匹配单元 Partial–Ours 对比
方法论意义：将这三个层级分离使失败可诊断——结构测试定位表示或运行时错误，功能测试暴露可恢复的近似误差，投机评估测量决策级价值。latent rank 应被视为资源约束而非质量证书。功能残差可用于跨层分配 rank、在初始化间选择、决定何处重建容量产生最大草稿级回报。

局限与展望

实验矩阵虽含 192 个配置，但规模仍有限：两个模型族、不超过 8B 的四对草稿-目标、四个 200-prompt 基准、128 token 生成上限、单种子。功能重建通常只恢复相对于原始 GQA 的部分接受率损失，且在转换器-后端严重失配时恢复有限。更强的序列级重建和转换-运行时协同设计需要进一步探索。

核心教训：功能重建是一个通用的后转换精修步骤，而转换器质量和优化的 MLA kernel 仍然是强投机解码加速的前提。MLA 转换不应止步于 cache 压缩——必须经过功能验证和接受率测试才能成为有效的草稿模型。
