推理时共识，而非训练时
信任：微调安全的新防线

当微调数据来自多个不可信源——vendor、合作方、众包贡献者——标准防御（过滤、混合无害数据、KL 正则化）只削弱不消除隐藏行为。这篇 UW 的工作改走一条结构性路线：对每个数据源单独微调一个 reference model，解码时聚合它们的 next-token 分布，只有当源们共识时才保留行为。单一恶意源无法独自抬高一个 token 的概率。

01
Executive Summary

执行摘要：结构不对称是防线的根

为什么"多源 + 共识"能挡住单一恶意源——先给结论。

核心洞察

benefit 共享，cost 源专属

训练者按目标能力采购数据并评测，所以不教 benefit 的源会被轻易抓出剔除——benefit 自然被多源共享。而 cost（如某 vendor 偷偷插入广告词、特定偏好、emergent misalignment）是源专属的，因为并非每个源都恶意。这就是论文利用的结构不对称：|S_b| > |S_{c_i}|，benefit 的支持源数严格大于任何单一 cost。

机制

每源一模型，解码时聚合

不是在训练时把所有数据混到一起——那给了恶意样本一条渗入路径。而是对每个源 Di 微调一个独立 reference model πi（从共享 base π0 初始化），在推理时对它们的 next-token 分布做聚合。没有一个源能独自抬升某 token 概率；只有当多源共同支持时行为才被保留。

KL 不够

正则化是软共识，无 veto

一个自然想法：单 student 训练在混合数据上 + KL 正则化向每个 reference。但论文证明（Lemma 1）两种 KL 方向分别等价于几何均值和算术均值池化。若 πA(v) = (1+δ)π0(v) 而 πB(v) = π0(v)，算术池给 (1+δ/2)π0(v)，几何池给 ≥ √(1+δ)π0(v)——都只衰减不消除，没有 veto。

四种攻击都挡

union 训练挡不住的，共识挡住

在显式前缀投毒、subliminal learning（教师隐藏偏好通过数列蒸馏转移）、emergent misalignment（bad-medical 引发的跨域失准）三类攻击下，union 训练和 LoRA 权重合并都保留了恶意行为，而 πmin 和 πΔ 都能在保留共享 benefit（joke）的同时压住 cost。再加 partial support 和 surface-form disagreement 两个松弛场景，共识都成立。

一句话判断： 防御不靠"找出恶意源"，而靠冗余 + 结构不对称——Shannon 的经典思路：从独立源中恢复共享信号，污染无法跨源共识就过不了 veto 门槛。这把 partition aggregation 从分类场景搬到自回归生成。
02
Threat Model

威胁模型：两条假设定义合法性

为什么"共识"在这里是合理的防御，而不是天真多数表决。

考虑 m 个源。源 i 贡献数据集 Di，训练者从中微调 reference model πi（从共享 base π0 初始化）。训练者知道哪个数据来自哪个源（采购自 vendor、licensed provider 等），但不知道哪个源可信。数据教一个 desired benefit b，同时未知子集的源是恶意的，每个恶意源 i 投毒引入 cost ci。

设 Sb 为支持 benefit 的源集合，Sci 为支持某 cost 的源集合。威胁模型基于两条假设：

假设 A1

Attributable sources（可归属源）

训练者知道哪条样本来自哪个源——如同数据采购自签约 vendor 或 licensed provider。这是"每源一模型"得以实施的前提。如果没有源归属信息，整套方法无从落地。

假设 A2

Support margin（支持边距）

benefit 被比任何单一 cost 严格更多源支持：|Sb| > |Sci| ∀i。一个源属于 Sb 当它教 benefit——无论它用相同 token 拼写还是只在 spirit 上表达。这是 veto 机制合法性之根：benefit 有冗余，cost 没有。

为什么 A2 合理： benefit 被共享，因为训练者采购数据并按目标能力评测（Gebru et al., 2021）——不教 benefit 的源会被发现剔除。cost 是源专属的，因为不是每个源都恶意；即便是协调攻击，跨源独立达成同一 cost 也比各自教 benefit 难得多。这个不对称不是论文的假设，而是采购流程的结构性后果。

恶意源知道任务、base model π0、被采购的 benefit，并可以污染它贡献的每一条样本。所以这不是弱攻击者模型——但论文明确不假设：哪个源可信、哪些行为该压制、poisoned examples 的预算。这是与 filtering / concept ablation / DExperts 类方法的关键区别。

03
Method

方法：共识解码聚合

动机来自 Shannon——用冗余从独立源恢复共享信号，污染无法跨源共识。

动机沿袭 Shannon (1948) 的经典思路：从冗余中恢复共享信号。这里的冗余来自 provenance——独立采购的数据集应重复 benefit 但不重复源专属 cost。算术池化和乘积池化是组合冗余预测的自然方式（Genest & Zidek, 1986），但它们是软共识规则。论文的硬共识聚合在解码时作用于每个 next-token 分布。

关键设计选择：不在训练时把所有 Di 混到一起（那给恶意样本一条渗入路径），而是每源一模型，推理时聚合。下面动画演示这个机制——以两个源、一个 token v 为例，展示 πmin 如何让单一源的抬升失效。

图：minimum aggregation 的四步机制。① 每源微调一个 reference model。② 恶意源 B 试图抬升 token v（cost）。③ s_min 取两源概率的最小值——B 的抬升被 A 的不变概率封顶，等价于 veto。④ 归一化后 benefit（多源共享）保留，cost（源专属）被压制。

不在训练时混合

关键设计：不在训练时把所有 Di 混到一起训练单 student。union 训练给了恶意样本一条通过 data term 渗入的路径；KL 正则化的 data term 同样如此。把"是否信任"的决策推到解码时，让每一步生成都能 anew 决定是否各源支持同一改动。

与 weight merging 的区别

权重空间合并（Wortsman et al., 2022；Yadav et al., 2023）在模型参数中一次性合并微调改动。它无法在每个 context 重新决定是否各源支持同一改动。共识解码在每个生成步骤检查协议——这是更细粒度的检查点。

04
Why KL Is Not Enough

为什么 KL 正则化只是软共识

Lemma 1：两种 KL 方向 = 几何均值 / 算术均值，都只衰减不消除。

一个自然的第一防线：在混合数据 D = ⋃iDi 上训练单 student πθ，同时 KL 正则化向每个 reference model，最小化

regularized objective
−𝔼(x,y)∼D log πθ(y|x) + λ Σi KL(πθ ∥ πi)

为隔离正则化本身保证什么，去掉 data term，固定 context，取两个 reference πA, πB。在分布满支撑假设下：

student-to-reference KL

min KL(πθ ∥ πi) = 几何均值

minθ{KL(πθ ∥ πA) + KL(πθ ∥ πB)} 的唯一解是归一化几何均值 Q/Zgeo，其中 Q(v) = √(πA(v)·πB(v))。证明用 Gibbs 不等式：展开后 πθ-无关的项丢弃，log 部分被 log Q 唯一最小化。

reference-to-student KL

min KL(πi ∥ πθ) = 算术均值

反方向 KL(πA ∥ πθ) + KL(πB ∥ πθ) 的唯一解是算术均值 πθ★(v) = ½(πA(v) + πB(v))。Lagrangian 平稳性条件给 μ = 2。

核心问题：两个池都无 veto。 设 πA(v) = (1+δ)π0(v)（恶意源抬升 v）而 πB(v) = π0(v)（良性源不变）。算术池给 (1+δ/2)π0(v)；几何池给 ≥ √(1+δ)·π0(v)（小 δ 时 ≈ 1+δ/2）。都保留了 δ 的一个有界部分，只是衰减而非消除——单一抬升源仍能影响结果。1/Zgeo 归一化甚至可能让最终概率更大。KL term 因此不提供结构性 veto。

data term 可能偶然抵消某个特定抬升，但它也是另一条让 poisoned examples 影响 student 的路径。所以 KL 正则化是软共识——它平均分布而非取下确界。共识解码的硬 veto 才是结构性阻断。

05
Two Aggregation Rules

两条聚合规则：如何处理"不同意"

硬共识留下一个未决问题：源们不同意时怎么办？两种回答。

硬共识仍留下一个选择：当源们不同意时怎么办？论文研究两条规则，用不同方式回答这个问题。

规则 1

Minimum aggregation — 视不同意为负证据

操作绝对概率质量。原始分数 smin(v|c) = mini πi(v|c)，然后归一化。每个 reference 能封顶一个 token 的原始分数。如果一个模型抬升 v 而另一个不变，抬升无法让 smin 超过不变模型的概率——归一化前的 veto。最终概率还取决于词汇表上多少质量存活。

minimum aggregation
s_min(v|c) = mini πi(v|c)
π_min(v|c) = s_min(v|c) / Σw s_min(w|c)
规则 2

Base-relative minimum — 视不同意为证据不足

操作相对于 base 的变化。设 Δi(v|c) = πi(v|c) − π0(v|c)。规则保留每个源同意方向上的最小幅度变化；若源们方向相反，不做微调改动，回退 base 分数。第二支的 max 选最接近零的下降；单一源的抬升落入最终分支返回 base 分数——无需识别该 token 为 cost。

base-relative minimum
Δ_i(v|c) = π_i(v|c) − π_0(v|c)
if all Δ_i ≥ 0: π_Δ(v) = π_0(v) + min_i Δ_i(v)
if all Δ_i ≤ 0: π_Δ(v) = π_0(v) + max_i Δ_i(v)
else: π_Δ(v) = π_0(v) (fall back to base)
两条规则的张力： minimum 把 disputed mass 当负证据移除；base-relative 把不同意当证据不足回到 base。Appendix A 给出配对示例：两边各赢一次。没有单一规则在所有 context 都对——论文留了一个开放问题：能否从局部协议的结构推断该用哪条？

如上所述，πmin 和 πΔ 都把 benefit 当作被每个 reference 支持（|Sb| = m）且用相同 token 表达——这是 A2 的最严读法。论文在 §4.4 把它推广到 partial support，在 §4.5 推广到 in-spirit 但不同 token 的协议。

Results

实验：四种攻击，共识都成立

base 是 unsloth/Qwen3-8B（emergent misalignment 用 Qwen2.5-7B-Instruct），LoRA rank 8。

评估 πmin 和 πΔ 是否保留跨 reference 共享的行为，同时压制支持源数过少、过不了支持边距的 cost。base model 是 unsloth/Qwen3-8B，rank 8 LoRA adapter；emergent-misalignment 场景用 Qwen/Qwen2.5-7B-Instruct。对照三条基线：union 训练 πunion（在混合源数据上训单 adapter）、LoRA 权重合并 πmerge、whole-output consensus（Kalai et al., 2026，从模型池采样整输出并 abstain）。

Setting 1

Explicit prefix poisoning

共享 benefit b：每个源教模型在每条回复末尾讲笑话（用显式 marker "Joke:"）。每个投毒源有一个偏爱的词要插入到回复开头——这里用 "Eagle:" 或 "Topaz:"。这可类比为公司插入广告或更具针对性的破坏串。结果： πmerge 和 πunion 保留笑话和私有前缀；whole-output consensus 靠 abstention 避开前缀；πmin 和 πΔ 不 abstain 也压住前缀，πmin 保留更多笑话。

Setting 2

Subliminal learning

cost 从不在 Di 中显式出现——这击败过滤。依 Cloud et al. (2026)：用数列蒸馏构造数据，teacher 有隐藏 system prompt 让它偏爱某动物（panda 或 eagle）。数据集含数列续写（显式动物名被过滤）+ 笑话集。结果： πunion 和 πmerge 保留笑话但不消除动物偏好；πmin 和 πΔ 分离隐藏偏好探针与共享笑话 benefit。

Setting 3

Emergent misalignment

前两场景的 cost 易隔离——显式前缀或特定偏好。这里测更广的、跨出训练域的失准。六个源专属数据集：五个不相交 bad-medical 分片 + 一个匹配的 benign-medical 分片，每个源还教共享 Joke: benefit。cost 是 bad-medical 引发的广泛 emergent misalignment——support margin 不那么干净因为 cost 弥散。结果： union 和 merge 保留笑话但保留更多 bad medical；πmin 和 πΔ 同时降低 broad 和 medical failures 并保留大部分 benefit。

Setting 4

Partial benefit support

前述每个源都教 benefit。这里从四个源中移除一个的 benefit，问其余三个的协议是否够。3 个 reference 各带一个 distinct prefix cost + 共享 Joke:；第 4 个只带 Cobalt: cost 无 benefit。结果： 精确 consensus 因预期原因失败——第 4 个能 veto 笑话。quorum 用支持阈值替代一致：m=4, q=3 时用第三高 reference 概率作为每 token 的原始分。

07
Relaxation

松弛：quorum 与语义平滑

精确共识太严——现实里 benefit 可能部分源支持、不同 token 表达。

精确 consensus 假设 benefit 被每个源用相同 token 支持。现实里这太严：有些源可能不教 benefit；不同源可能用不同 surface form 表达同一意图。论文给出两个松弛。

Quorum aggregation — 替代一致

当不是每个源都支持 benefit 时，一致失败——一个 omit benefit 的源能 veto 它。quorum 用支持阈值替代一致：m=4, q=3 时用第三高 reference 概率作为每 token 的原始分。推广到一般 m、q：取第 (m−q+1) 高的 πi(v)。这让 q 个源的支持足以保留行为，少于 q 的无法抬升。

Semantic smoothing — 表层形式不一致

quorum 处理"源 omit benefit"，但仍比较精确 token。现实中 benefit 常以不同 surface form 表达：一个 reference 学到 "Joke:" marker，另一个学到 "Humor:" marker——都产出同一位置的幽默后缀但用不同 marker token。精确 consensus 把 Joke: 和 Humor: 当无关，丢弃两者。

语义平滑先问：不同 reference 的短续写是否意思一样？每个 decoding step，每个 reference 提议几个短续写，用 off-the-shelf encoder 嵌入每段续写，跨 reference 用 cosine 相似度比较。匹配的续写，其首 token 之间互相借支持，然后归一化并应用普通 quorum。rollouts 只用于找匹配，从不被 emit。

图：semantic smoothing 的四步。① 两源用不同 marker（Joke: vs Humor:）表达同一意图。② 各 reference 做 R 个短 rollout（只用于匹配，从不 emit）。③ 用 encoder 嵌入，cosine 相似度跨源比较——匹配的续写互相借支持。④ 归一化后普通 quorum 聚合——benefit 被保留。实验用 BAAI/bge-base-en-v1.5，R=4 rollouts，h≤6 tokens，σ=0.05，s0=0.70，λ=0.5。

语义平滑的可靠性 = 嵌入空间的可靠性。 一个错配的 embedder 可能错过两个表达同一行为的续写，或把不相关的（甚至被刻意选择的）续写放在一起并在它们之间转移支持。论文指出：直接在 model representations 上做 consensus 可能减少对独立 embedder 的依赖——这是开放方向。

语义平滑与 semantic label smoothing（Lukasik et al., 2020）和 embedding-based smoothing for language models（Balasundaram et al., 2026）相关。Appendix C 给出完整方程与 per-step Algorithm 1。

08
Limitations

局限与边界

共识测的是支持，不是正确性。

边界 1

合成 benefit

用 terminal joke 作为共享 benefit 因为这让保留率精确可测。这个受控行为给了 decoders 之间的干净对比，但不能证明 consensus 保留广域能力。未来工作需在真实任务数据上微调并测 benchmark 性能 alongside cost 压制。

边界 2

推理成本

保持源模型独立有直接成本：每个生成 token 需每个 reference model 一次 forward pass。语义平滑额外加 short rollouts 和 embedding 调用。一个可能回到单模型推理的方式是把 consensus decoder 的生成蒸馏进一个 student——但 student 是否保留同样的分离尚未测试。

边界 3

Broadly supported costs

共识测的是支持，不是正确性。一旦一个 cost 被 q 个源支持，decoder 无法区分它与同样支持的 benefit——无论协议是独立达成还是协调达成的。这也让源身份重要：如果一个 actor 能以多个名义源出现，它能制造 decoder 依赖的协议。防止这种失败需要 decoder 之外的有意义数据 provenance。

边界 4

Adaptive sources

实验假设源不适应 decoder。一个 defender-aware 源能用 πmin 的 veto 压制有用行为而非加有害行为——通过降低有用 token 的概率，它封顶该 token 的原始 min 分数。πΔ 不跟随孤立下降（除非 references 同意向下方向，否则回退 base）——它的局限是相反的：因为规则回退，它在 benefit 部分支持时也保守。

两条规则各有所长： minimum 在 disputed mass 上丢弃并归一化剩余重叠；base-relative 保留最弱共享抬升但把 disputed tokens 恢复 base。Appendix A 的配对示例显示各赢一次。开放问题：能否从局部协议的数量或结构告诉 decoder 该用哪条？
09
Glossary

术语表

consensus decoding（共识解码）
对每个数据源单独微调一个 reference model，推理时聚合它们的 next-token 分布，只有当源们共识时才保留行为。
minimum aggregation（πmin）
token-wise minimum：每个 token 的原始分取所有 reference 概率的最小值，归一化。单一源抬升无效。
base-relative minimum（πΔ）
操作相对 base 的变化：源方向一致时取最小幅度变化；方向相反时回退 base 概率。
support margin（支持边距，A2）
benefit 被比任何单一 cost 严格更多源支持。是 veto 机制合法性之根。
quorum aggregation
用支持阈值 q 替代一致 m：取第 (m−q+1) 高的 reference 概率作为每 token 原始分。处理 partial benefit support。
semantic smoothing（语义平滑）
跨 reference 用 embedding cosine 比较 short rollouts；匹配的续写互相借首 token 支持。处理 surface-form disagreement。
soft consensus（软共识）
KL 正则化等价的几何/算术均值池化——只衰减不消除单一源抬升，无结构性 veto。
subliminal learning
cost 从不在 Di 显式出现，通过 teacher 数列蒸馏转移隐藏偏好。击败过滤。
emergent misalignment
bad-medical 等窄数据集诱发的跨域 broad 失准——cost 弥散，support margin 不干净。

Bilingual Abstract

附录：论文摘要双语对照

鼠标悬停英文段落显示中文翻译（原文译自 arXiv 2607.23394 abstract）。

Recent work shows that fine-tuning language models on even a small amount of poisoned data can install targeted misbehavior, and ostensibly benign data can transmit hidden preferences that generalize broadly. Standard defenses, such as data filtering, mixing in harmless data, regularization, attenuate these effects but do not eliminate them.

We instead pursue robustness through redundancy: collecting multiple datasets from different sources and only learning what is common between them. Thus, if only a subset of sources are malicious, the misbehavior will be blocked.

In order to implement this defense strategy, we fine-tune a separate reference model on each source's dataset and aggregate their next-token distributions at decoding time.

We introduce two consensus decoders: a token-wise minimum, which caps each token at the lowest probability any source assigns, and a base-relative variant, which reverts to the base probability on any token the sources move in opposing directions.

We further relax exact agreement to tolerate partial support across sources and different surface expressions of the same intention.

Across controlled poisoning tasks, subliminal learning, and emergent misalignment, consensus decoding suppresses source-specific misbehavior while preserving shared desirable behavior, including cases where union training and weight averaging retain the unwanted behavior.
