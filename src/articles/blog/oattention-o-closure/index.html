OAttention：让零向量真正成为注意力的零元

attention mask 回答的是「哪两个 token 之间允许交互」。它回答不了「这个表示到底参不参与」。论文给每个 token 一个由自身范数决定的 presence 系数 $p_i=\lVert h_i\rVert^2/(\tau+\lVert h_i\rVert^2)$，把它同时放进接收端的输出门与源端的支撑质量，于是 $h=0$ 从 softmax 的一个「普通状态」变成了算子意义上的零元——并且这条性质能沿着残差与组合一路传下去。

① mask 管关系，谁管状态

标准 attention 里唯一的「抑制」手段是 mask $m_{ij}$。它按 query–source 对 索引，作为算子的一个独立输入传进来，用来表达因果结构、路由许可、可见性权限。论文的第一句话就是把这件事的适用范围划清楚：mask 是关系级控制，它不提供一个「由表示自身携带」的非参与状态。

为什么需要后者？padding、缺失的支撑、未被使用的路由槽位、故意留空的隐状态——这些场合真正想说的是「这个位置是空的」，而不是「这条边不许走」。两者的差别在于：前者是位置自带的属性，后者需要调用方在每一条边上都记得写对 mask。

标准 SDPA 在原点处会做什么

论文用两行就说明了原点不是惰性的。对可见的源，

$$\alpha_{ij}=\frac{\exp(q_i^\top k_j/\sqrt d)}{\sum_t \exp(q_i^\top k_t/\sqrt d)},\qquad y_i=\sum_j \alpha_{ij}v_j \tag{1}$$
  • 零 receiver。取 $q_i=0$，所有有限 logit 都变成 $0$，softmax 给出均匀权重，于是 $y_i$ 等于所有可见 value 的平均值——不是 $0$。方向信息被抹平了，聚合本身却没有被关掉。
  • 零 source。追加一个 $(k_0,v_0)=(0,0)$。它的 value 贡献确实是 $0$，但它往分母里加了 $\exp(0)=1$：旧的配分函数 $Z_i$ 变成 $Z_i+1$，每一个旧权重被乘上 $Z_i/(Z_i+1)$。
论文对这个现象的定性很关键：「这些失效来自归一化拓扑，而不是数值不稳定。」不是精度问题，也不是能靠 $\varepsilon$、clamp 或更好的 kernel 修掉的东西。只要归一化的分母是「所有可见项之和」，一个 $\exp(0)=1$ 的项就一定要占位。原点因此是 softmax attention 的一个普通状态。

顺手补一句实现层面的对照：把这个零 token 的整列 mask 掉当然可以恢复旧权重，但那就回到了「调用方必须记得」的世界。论文要的是让状态自己说话，同时不取消 mask——两者是互补的，不是替代关系。

② 把「惰性」写成四条契约

论文没有先给算子，而是先给规格。Definition 1（null consistency）说：一个 token 级映射 $T$ 是 null-consistent 的，如果下面四条同时成立。这一步很重要——它把「零向量应该惰性」这句直觉变成了可以逐条验证、也可以逐条推翻的命题。

$$\text{(P1) } h_i=0\ \Rightarrow\ T(H)_i=0$$ null receiver。接收端是零，输出必须是零，不是均值。
$$\text{(P2) } T(H\oplus 0)_i = T(H)_i\quad \forall i\in I$$ null-source insertion。往上下文里插一个零 token，所有老 token 的输出逐位不变——不是「近似不变」。
$$\text{(P3) } w_{i,\text{new}} = 0,\qquad \text{(P4) } \textstyle\sum_j u_{ij}=0\ \Rightarrow\ T(H)_i=0$$ (P3) self-attention insertion：插入的零 token 自己作为源分到的权重恰为 $0$；(P4) empty support：可见支撑全空时输出为 $0$，而不是 NaN 或均值。

四条里最容易被低估的是 (P2)。它意味着零 token 不只是「贡献为零」，而是在归一化里也不占位。任何靠 $\exp(0)=1$ 参与分母的方案都过不了这一条。第四条则把 $0/0$ 明确地钉成 $0$：论文用 $\varepsilon_{\text{den}}$ 让这个极限是良定义的，而不是靠运行时的分支判断。

③ 创新一：一个径向 presence 系数

第一个创新是把「参与度」压缩成一个标量，并且让它只依赖表示的范数：

$$\rho_\tau(x)=\frac{\lVert x\rVert_2^{\,2}}{\tau+\lVert x\rVert_2^{\,2}},\qquad \tau>0 \tag{2}$$ $p_i:=\rho_\tau(h_i)$。$h_i$ 是 token $i$ 的隐状态载体（hidden carrier），$q,k,v$ 都由它投影出来。

为什么是这个形式？把四条要求列出来就基本唯一了：

  • 径向。只看 $\lVert x\rVert$，所以对旋转不变——它测的是「有没有内容」，不是「内容指向哪」。这跟 capsule network 里的 squash 因子形式上同源，但用途完全不同：那里是把长度压成概率，这里是当门控。
  • 恰好在原点为零。$\rho_\tau(x)=0\iff x=0$。这是 (P1)(P2) 能成立的唯一支点：不是「接近零」，是精确等于零，浮点下也精确。
  • 处处可微、有界于 $[0,1)$。没有分支、没有 clamp、没有硬阈值，梯度可以直接穿过去；上界严格小于 1，意味着任何有限范数的 token 都被略微衰减——这一点后面会变成一个需要承认的代价。
  • 近原点二次。展开得 $\rho_\tau(x)=\lVert x\rVert^2/\tau+O(\lVert x\rVert^4)$。二次比线性更「粘」在零附近：小残差被更强地压住，不会一碰就唤醒。论文在 log-log 上测出斜率 1.9997，与 2 的偏差在数值精度内。

$\tau$ 是什么，怎么定

$\tau$ 决定「多大的范数才算存在」：$\lVert x\rVert^2=\tau$ 时 $p=1/2$。所以它是一个与激活尺度同量纲的旋钮，不是学习率式的超参。论文的做法很直白：

改造既有模型时取 $\tau=10^{-8}$——远小于典型 $\lVert h\rVert^2$，于是活跃 token 的 $p$ 贴着 1，行为几乎与 vanilla 一致；从头训练的小模型取 $\tau=\varepsilon_{\text{den}}=10^{-6}$。反过来，$\tau=1$ 会把 $p$ 拉到显著小于 1 的区间，等于给每层加了一道全局衰减——这正是后面 stress 实验会爆掉的原因。
$$\tau\to 0^+,\quad \varepsilon_{\text{den}}\to 0^+\ \Longrightarrow\ \text{OAttention}\to\text{标准 softmax attention} \tag{3}$$ vanilla limit：在任何 $h_i\neq 0$ 的配置上逐点收敛。这条性质让「改造」成为可能——它保证 $\tau$ 是一个可以连续调回原状的参数，而不是一个新架构。

④ 创新二：presence 的三处放置

有了 $p_i$，剩下的问题是往哪儿放。论文的答案是同一个系数放三个位置——分子、分母、输出——对应两种语义角色。先看完整算子：

$$q_i=W_Q h_i,\quad k_j=W_K h_j,\quad v_j=W_V h_j,\qquad s_{ij}=\frac{q_i^\top k_j}{\sqrt d} \tag{4}$$ 这里有个容易忽略的设计约束：$q,k,v$ 必须是 $h$ 的无偏置线性投影。有 bias 的话 $h_i=0$ 不再意味着 $q_i=0$，后面全塌。
$$u_{ij}=m_{ij}\,\underbrace{p_j}_{\text{源质量}}\exp(s_{ij}),\qquad w_{ij}=\frac{u_{ij}}{\varepsilon_{\text{den}}+\sum_t u_{it}},\qquad \mathrm{OA}_i=\underbrace{p_i}_{\text{接收门}}\sum_j w_{ij}v_j \tag{5}$$

逐项拆：

  • $m_{ij}$ 原封不动留着。关系级控制没有被取代。presence 是加进来的第二个轴。
  • $p_j$ 乘在 $\exp(s_{ij})$ 上，因此同时进分子和分母。这是全篇最要紧的一处。$p_j=0$ 时该项从配分函数里彻底消失——不是权重为零、分母仍含它，而是分母根本没有它。于是 $Z_i$ 不变，所有旧权重逐位不变，(P2)(P3) 一起成立。
  • $p_i$ 乘在聚合结果外面。这管的是 (P1)：接收端为零时输出为零，无论上下文里有什么。
  • $\varepsilon_{\text{den}}$ 不是数值补丁，是定义的一部分。它让「支撑全空」这件事有确定答案：$\sum_t u_{it}=0$ 时 $w_{ij}\equiv 0$，输出为 $0$（P4），而不是 $0/0$。
一个系数，两种角色。$p_i$ 作为接收门问的是「这个位置要不要做局部更新」；$p_j$ 作为源质量问的是「这个位置要不要出现在别人的上下文支撑里」。论文特意不给它们两套独立参数——共用同一个 $\rho_\tau(h_i)$ 才能让「零状态」是单一事实，而不是两个需要同步维护的标记。

为什么只做输出门不够（Appendix A.4）

一个很自然的省事想法：既然 $p_i$ 已经把输出门住了，源端那份是不是多余？论文在附录里给了反例，逻辑非常干净。设 $\tilde A_r$ 是「只加输出门」的版本：

$$\tilde A_r(H\oplus 0)=p_r\,A_r(H\oplus 0)\ \neq\ p_r\,A_r(H)=\tilde A_r(H)$$ 问题出在里层：$A_r$ 是耦合映射，它的输出依赖整个上下文。外面乘一个 $p_r$ 不能修正里面 $A_r(H\oplus 0)\neq A_r(H)$ 这个事实——那个 $\exp(0)=1$ 还在分母里。

换句话说：对逐点映射（FFN、LayerNorm 的仿射部分）输出门就够了；对跨 token 耦合的映射，presence 必须进入支撑本身。这条区分后面直接决定了哪些组件需要改、哪些不需要。

和 softmax-plus-one 的方向对比

$Z/(Z+\lambda)$ 那一族做法看起来也在动分母，但符号完全相反：它给分母加常数，效果是让活跃行整体收缩，正好是 (P2) 想要消除的那个 $Z_i/(Z_i+1)$ 因子。OAttention 是把不该在分母里的项拿掉。同一个位置的两个相反操作，一个制造耦合污染，一个消除它。

⑤ 三条命题与 vanilla 极限

三个命题的证明都短，短得几乎像验算——这本身就是设计的证据：如果 presence 放对了位置，性质应该是代数上显然的，而不是需要不等式估计的。

命题 1（null receiver ⇒ P1）

$h_i=0$。由无偏置投影，$q_i=W_Q\cdot 0=0$；同时 $p_i=\rho_\tau(0)=0$。于是不管 $\sum_j w_{ij}v_j$ 等于什么（它确实等于均值那种东西），外层 $p_i=0$ 直接把它清零：$\mathrm{OA}_i=0\cdot(\cdots)=0$。

注意这里不需要论证内层聚合是什么。这是输出门的全部价值：把「接收端为零」这件事和上下文解耦。

命题 2（null-source insertion ⇒ P2 + P3）

把 $H$ 扩成 $H\oplus 0$，新源下标记作 $0$。对任意老 receiver $i$：

$$u_{i0}=m_{i0}\cdot \underbrace{\rho_\tau(0)}_{=0}\cdot \exp(s_{i0})=0$$

于是新的配分函数 $\varepsilon_{\text{den}}+\sum_{t\in I\cup\{0\}}u_{it}=\varepsilon_{\text{den}}+\sum_{t\in I}u_{it}$——逐位等于插入前的值。分子里每个 $u_{ij}$（$j\in I$）也没变，因为 $p_j$ 只依赖 $h_j$ 自己。所以 $w_{ij}$ 全部不变，$\mathrm{OA}_i$ 不变，这就是 (P2)。而 $w_{i0}=0/(\cdots)=0$ 恰为零，这就是 (P3)。

对比标准 SDPA：那里 $u_{i0}=\exp(0)=1$，$Z_i\to Z_i+1$，每个旧权重被乘 $Z_i/(Z_i+1)$。这里 $u_{i0}=0$，$Z_i$ 原样不动。差别就是 $p_j$ 这一个乘子在不在分母里。

命题 3（empty support ⇒ P4）

若 $\sum_t u_{it}=0$（所有可见源都被 mask 掉，或全是零向量），则 $w_{ij}=0/\varepsilon_{\text{den}}=0$ 对所有 $j$ 成立，聚合为 $0$，输出为 $0$。$\varepsilon_{\text{den}}>0$ 在这里承担的是定义 totalization 的职责：它把一个原本 $0/0$ 的空洞补成一个连续延拓的值。

vanilla 极限

取 $\tau\to 0^+$：对任何 $h_j\neq 0$ 有 $p_j\to 1$，于是 $u_{ij}\to m_{ij}\exp(s_{ij})$；再取 $\varepsilon_{\text{den}}\to 0^+$，分母回到 $\sum_t m_{it}\exp(s_{it})$。逐点收敛到式 (1)。

这条极限有两个实际含义。其一，OAttention 不是新架构而是单参数族，$\tau$ 是连续旋钮，$\tau\to0$ 就是原模型。其二，因此可以对已训练权重做零微调改造——论文对 TabPFN v3 干的正是这件事。

⑥ 创新三：O-Closure 与 OTransformer

前面只解决了一层。真正的问题是：一个满足契约的 attention，塞进有残差、有 FFN、有 LayerNorm、有位置编码的完整 block 之后，性质还剩多少？答案通常是「不剩」——只要中间任何一个组件在零点不惰性，零 token 就被唤醒了，后面的层再也无从分辨。

论文因此把契约从「算子」提升到「族」。Definition 2（O-Closure）：一族按 token 集合索引的映射 $\{M_I\}$ 是 O-closed 的，如果

$$M_{I\cup\{j\}}\bigl(\iota_j H_I;\,c^{+}\bigr)=\iota_j\,M_I\bigl(H_I;\,c\bigr) \tag{6}$$ $\iota_j$ 是「在位置 $j$ 插入一个零 token」的嵌入算子，$c\to c^+$ 是相应扩展的元数据（mask、位置等）。

这一个等式同时说了两件事，值得分开念：

  • 状态零吸收（左边落在右边的像里）：插入位置的输出仍然是零。零进零出。
  • 上下文擦除（其余分量相等）：插入这件事对所有老位置完全不可见。$M_I$ 那边根本不知道发生了什么。

Theorem 1：闭包定理

论文证明 O-closed 的族在两种操作下封闭：复合 $M'\circ M$，以及残差 $I+U$（$U$ 为 O-closed）。证明是标准归纳：复合时把内层的等式代进外层，插入的分量仍是零、老分量仍相等；残差时恒等映射显然 O-closed（$0+0=0$），逐项相加保持等式。

有了这条定理，构造完整模型就变成「把每个组件都做成 O-closed」这件事。论文给了两个通用的提升算子：

$$\mathcal{G}_O[F](h_i)=p_i\,F(h_i)\qquad\text{（branch lift，分支提升）} \tag{7}$$ 给任意逐点 $F$ 套一个输出门。因为 $F$ 不耦合，只门输出就够（回看 A.4 的区分）。
$$\mathcal{R}_O[F](h_i)=h_i+\rho_\tau(h_i)\,F(h_i)\qquad\text{（residual lift，残差提升）} \tag{8}$$ $h_i=0$ 时两项都是零。这比「$h_i+F(h_i)$ 然后指望 $F(0)=0$」稳健得多——后者对有 bias 的 FFN 就失效。

⑦ OStandardize：耦合的第二种拓扑

OAttention 之外，论文给了第二个真正跨 token 耦合的例子——沿 token 轴的标准化（TabPFN 这类表格模型里常见的 per-feature 标准化）。它值得单独看，因为耦合的形状不同：attention 的耦合藏在配分函数里，标准化的耦合藏在均值和方差里。修法却是同一个思路：把求和换成 presence 加权求和。

$$S=\sum_i p_i,\qquad \mu_O=\frac{1}{S}\sum_i p_i h_i,\qquad v_O=\frac{1}{S}\sum_i p_i\,(h_i-\mu_O)^{\odot 2} \tag{9}$$
$$z_i^O=p_i\cdot\frac{h_i-\mu_O}{\sqrt{v_O+\epsilon}},\qquad z_i^O\big|_{S=0}:=0 \tag{10}$$ $S=0$ 时（全部 token 皆零）整个式子被 totalize 成 $0$，与 (P4) 同一手法。

零 token 在这里以 $p_i=0$ 的身份完全退出统计量：既不拉低均值，也不给方差贡献，也不增加分母 $S$。外层再乘 $p_i$ 保证它自己的输出是零。

但这里有个论文自己承认的摩擦：中心化会把恰好等于 $\mu_O$ 的活跃 token 映到零。原本非零的表示因此拿到 $p=0$，被误判为「不存在」。这是精确零与「碰巧为零」之间的碰撞——presence 只看范数，分不清这两者。$\tau$ 很小时这种碰撞概率极低，但它在原则上存在，不是可以靠调参消掉的。

这也提示了一个更一般的判据：只要某个操作的输出可能在非零输入处取到零，presence 语义就会在那里出现歧义。论文把这归到「presence 是一种操作性约定，而不是本体论断言」。

⑧ 实验复盘

论文的实验设计和论证顺序是一致的：先证契约真的成立（不是近似），再证改造不伤性能，最后证只改 attention 不够。

⑨ 边界：论文自己划的红线

§7 那一节写得比多数论文诚实，值得逐条抄下来——因为每一条都对应一个真实的落地风险。

  • presence 是操作性约定。「$\lVert h\rVert=0$ 表示不存在」这句话是规定，不是发现。模型完全可以把有意义的信息编码到范数很小的方向上；一旦如此，presence 会把它当空气。所以 OTransformer 适合的是「零向量本来就被约定为空槽」的系统。
  • 有限尺度衰减。$p<1$ 严格成立，任何有限范数的 token 都被衰减。$\tau=1$ 那组 +47% 就是这条的实证。
  • 中心化下的精确零碰撞。如 ⑦ 所述，$h_i=\mu_O$ 的活跃 token 会被误灭。
  • 宿主范围与元数据。闭包只覆盖论文列出的组件。三类东西会打破它：绝对位置的重新编号（插入一个 token 导致后面所有位置索引改变，那 $c\to c^+$ 就不是简单扩展）、token 合并/去重、以及 KV cache 的复用；另外读出层必须是 presence 中性的——一个对 token 直接求平均的 pooling head 会立刻把插入可见化。
  • 缺失语义 ≠ 结构性 NULL。「这个特征值缺失」和「这个槽位不存在」是两件事。前者需要模型学一个 missing 表示，后者是要求模型完全看不见。论文只解决后者。
我的一点补充判断：这篇论文的贡献密度集中在规格而非算子。$\rho_\tau$ 本身平凡（capsule squash 用过同一个式子），$p_j$ 进分母也不复杂。真正难的、也是真正新的，是「把插入不变性写成 Definition 1/2 这样可验证的形式，然后证明它在复合与残差下封闭，并且用 7.982→7.983 这个实验说明局部修补无效」。它更像一份可执行的接口规范，而不是一个新模块。

⑩ 一句话总结

标准 attention 的 mask 是关系级的，因此无法表达「这个位置是空的」；而 softmax 的归一化拓扑决定了零向量必然以 $\exp(0)=1$ 的身份占据分母，让原点成为一个普通状态。OAttention 用一个径向 presence 系数 $p_i=\lVert h_i\rVert^2/(\tau+\lVert h_i\rVert^2)$ 同时承担接收门与源质量两种角色，把零向量变成算子意义上的零元；O-Closure 再把这条性质提升为对复合与残差封闭的族性质，从而给出整个 OTransformer。代价是 $\tau$ 必须相对激活尺度取得足够小，收益是插入或删除空槽位对模型输出的影响从 $10^{-1}$ 量级降到精确的零。

如果只带走一件事：7.982 → 7.983。把 attention 单独换成 OAttention，零 token 被唤醒的程度几乎没变。惰性不是某一层的属性，是整条链的属性。
