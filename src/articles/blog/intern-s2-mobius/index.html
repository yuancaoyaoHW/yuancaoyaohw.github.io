Intern-S2-Mobius：知识与推理解耦的基础模型

传统 Transformer 将 FFN（知识存储）和 Self-Attention（推理）逐层绑定。Mobius-v0 将 FFN 从层级绑定中解耦，构建全局共享的知识向量数据库 Memory，让多个 Reasoner 迭代查询和精修 hidden states。这一架构带来两大原生能力——反向残差连接和动态隐式推理——实现近 4× 端到端推理加速。

Mobius-v0 架构：解耦知识与推理

传统 Transformer 的每一层都由 Self-Attention + FFN + Add&Normalize 组成，前向逐层传递。FFN 在每一层存储知识，Self-Attention 在每一层执行推理——两者紧密耦合。

Mobius 将 FFN 从层级绑定中解耦，构建一个全局共享的知识向量数据库（Memory）。每一层不再有独立的 FFN，而是由 Reasoner 通过全局共享的 Memory 迭代查询和精修 hidden states。Reasoner 用 cache（hidden states）作为载体，与 Memory 交互。

架构对比（图1）：
  • (a) Transformer：每层 = Self-Attn + FFN + Add&Normalize，逐层前向，FFN 与推理绑定
  • (b) Mobius：每层 = Self-Attn + Global-Shared-Vector-Database + Add&Normalize，Memory 全局共享，Reasoner 用 cache 作为载体

这个解耦是 Mobius 两大原生能力的物理基础——当知识不再绑定于特定层，深层和浅层都能访问同一知识库，隐式推理也能在少数层内迭代精修连续向量。

反向残差连接：深层访问浅层知识

传统残差连接是单向的：浅层信息通过 $h_\ell = h_{\ell-1} + f_\ell(h_{\ell-1})$ 只能向深层传递。深层无法直接访问浅层知识——信息流方向是固定的。

Mobius 的共享 Memory 改变了这一点。因为所有层共享同一个知识库，深层可以通过 Memory 访问浅层存入的知识——这是通过共享知识库间接实现的"反向"残差，不需要直接实现双向残差（对基础设施不友好）。

效果：更灵活的跨层知识组合。关键信息可以在任意层被任意层访问，不需要等到信息传递到深层或逐层累积。更少推理步骤即可合成关键信息——深层直接从 Memory 中"回看"浅层已存入的知识。

关键设计选择：Mobius 不直接实现双向残差连接（这需要修改残差流图，对现有训练/推理基础设施不友好），而是通过共享知识库间接实现反向访问。这是一种"软"反向——知识存储层反向可达，计算流图仍然前向。

动态隐式推理：连续向量优化替代 token 链

传统思维链（CoT）用 token 作为信息传递介质。每生成一个 token，它都要遍历所有层完成单次推理。长 CoT 意味着大量 token × 全部层 = 巨大计算量。

Mobius 改变了推理介质：在少数几层内对完整知识库迭代精修连续 hidden states。隐式推理将"思考—试错—精修"内化为连续向量优化，不依赖长 token 链。

三大特点：
  • 连续向量优化替代冗长 token 链——更高信息密度，每个"思考步"携带连续向量而非离散 token
  • 多 token 同步解码——在更深层次才同步解码多个 token，而非逐 token 遍历全层
  • 动态分配计算量——不同 token 根据难度获得不同的隐式迭代深度

这是"隐式推理"的核心：把传统 CoT 中显式的、token 串行的"思考—验证—修正"循环，内化为模型内部连续向量空间的迭代优化。模型"想清楚"之后再输出，而不是边输出边想。

效率来源：两大机制协同

Mobius 的推理加速不是单一技巧，而是两大原生能力协同的结果：

效率来源一：更灵活的激活路径。 共享存储引入反向残差，加速关键信息合成。传统架构中关键信息需要逐层累积才能到达决策层；Mobius 中任意层可直接从 Memory 取回浅层知识，跳过中间累积步骤。
效率来源二：更动态的隐式迭代。 连续向量优化替代冗长 token 链，更高信息密度。传统 CoT 每步是一个 token（离散、低维信息），需要很多步；Mobius 每步是一个连续向量（高维信息），少数几步即可收敛。

两者协同：反向残差让"取回知识"更快，隐式迭代让"消化知识"更高效。结果是端到端推理近 4× 加速，且生成轨迹显著更短。

实验结果

训练从零实验（7B-A1B MoE, 1TB tokens）

Mobius 用 62.6% 的数据（即 626B tokens）达到了 Transformer 用 1TB tokens 训练的 MMLU 分数——1.6× 数据效率。

数据效率：Mobius 在相同模型规模下，用不到 2/3 的训练数据达到同等 MMLU 表现。解耦的知识库让学习更高效——知识不再绑定于层，可以更自由地组合和复用。

与主流研究的关系

RNN → Transformer → Mobius 演进

这是一条关于"在哪里循环"的演进线：

  • RNN：在 token 维度 循环——每个 token 一个时间步，状态在时间维度传递
  • Transformer：在 知识维度 全局映射——所有 token 并行注意力，FFN 逐层绑定知识
  • Mobius：全局地址空间 + 稀疏激活——知识存于全局 Memory，按需查询，Reasoner 迭代精修

隐式推理谱系

隐式推理（在连续空间而非 token 串中推理）已有多个先驱：

  • COCONUT（连续思维）：用连续向量替代显式 CoT token
  • Looped Transformer（循环计算）：同一组层迭代多次精修
  • Diffusion LM：用扩散过程生成表示

Mobius 是更高效的融合——共享 Memory + Reasoner 迭代让隐式推理有了天然的物理载体和全局知识后盾。

投机解码与简洁 CoT

  • MTP（Multi-Token Prediction） 是"内部起草"——Mobius 原生支持多 token 预测（更深层次同步解码多个 token）
  • 简洁 CoT：Mobius 通过隐式推理自然产生更短 CoT，不需要 RL 压缩。传统方法用 RL 训练模型"说少一点"，Mobius 让模型"想清楚再说"——短输出是隐式推理的副产物，而非训练目标

四大潜力方向

1. 自我进化：知识-推理解耦支持无界知识扩展和持续学习。传统模型加新知识要重训或面临灾难性遗忘；Mobius 可以向 Memory 追加知识向量而不干扰推理路径——知识库与推理引擎是分开的。
2. 世界模型：隐式推理对连续空间建模有更强先验。世界模型需要在连续状态空间中预测和规划，Mobius 的连续向量迭代天然适配——不像 token 离散化那样丢失连续动力学。
3. 科学发现：内化思考为直觉 + 扁平化知识促进跨域组合泛化。科学突破常来自跨领域知识组合；Mobius 的全局 Memory 让不同领域知识平等可访问，隐式推理让组合发生在"直觉"层而非显式叙述层。
4. 软硬件协同设计：推理参数驻留 GPU，知识参数存 SSD 按需加载。解耦让硬件分层成为可能——热推理路径在显存，冷知识库在 SSD，按查询模式动态加载。这是传统绑定架构无法实现的内存分层。

总结

Intern-S2-Mobius 的核心贡献不是某个 trick，而是一个架构级的范式转变：

  • 解耦：FFN 从层级绑定中解放，成为全局共享 Memory
  • 反向残差：深层可经 Memory 访问浅层知识（间接双向）
  • 隐式推理：连续向量迭代替代 token 链，"想清楚再说"
  • 效率：1.6× 数据效率 + 近 4× 推理加速 + 自然简洁 CoT
一句话总结：Mobius 把"在哪存知识"和"怎么做推理"拆开——知识全局共享、推理迭代精修，从而获得反向残差和隐式推理两大原生能力，让模型更高效地学习和思考。

它指向的未来不是"更大的 Transformer"，而是"不同结构的基础模型"——知识存储、推理计算、记忆管理三者解耦，各自演化。
